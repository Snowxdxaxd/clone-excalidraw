# Скетч — совместная доска

Клон Excalidraw/Miro: бесконечная доска для набросков и схем с живым мультиплеером. Node 24, ESM, без сборки.

## Запуск

```bash
npm install
PORT=3013 node server.js
```

Открыть `http://localhost:3013`. Главная — список досок и кнопка «Новая доска». Доска живёт по ссылке `/b/<id>`, например `/b/demo` — демо-доска «Демо» (создаётся при первом старте, если её нет в базе).

## Что умеет

- Инструменты: выделение, рука, прямоугольник, эллипс, ромб, линия, стрелка, карандаш (свободная рука), текст, ластик — все иконки инлайновые SVG.
- Выделение рамкой, перемещение, ресайз за угловые ручки, удаление (Delete).
- Зум колесом к позиции курсора (0.2–4), панорамирование пробелом+перетаскиванием или инструментом «Рука», кнопка «Сброс вида», индикатор зума.
- Текст: инструмент «Текст» или двойной клик — textarea-оверлей, на blur содержимое сохраняется в элемент.
- Undo/redo локально (Ctrl+Z / Ctrl+Shift+Z), стек снапшотов на 100 шагов.
- Экспорт PNG (offscreen canvas с белым фоном, x2) и SVG (rect/ellipse/diamond как polygon, линия/стрелка/карандаш как polyline, у стрелки треугольная головка, текст как text/tspan).
- Мультиплеер: курсоры участников с именами и цветом из хэша имени, элементы синхронизируются по одному (LWW), счётчик участников. Свой ID — случайный на вкладку.
- Автосохранение всей доски в SQLite с дебаунсом 800 мс; при закрытии вкладки несохранённое уходит через sendBeacon.
- Вход по имени (cookie-сессия, lib/auth) — имя подписывает курсоры; доски доступны без сессии по ссылке.

## Архитектура

- `server.js` — API досок и WS-комнаты.
- `lib/` — каркас: `http.mjs` (роутер/статика), `db.mjs` (better-sqlite3, миграции), `ws.mjs` (WebSocketServer), `auth.mjs` (вход по имени), `util.mjs`.
- `public/js/main.js` — весь клиент: маршрутизация, редактор, отрисовка на двух канвас-слоях (сцена + оверлей курсоров), WS.
- БД: таблица `boards(id, name, elements_json, updated_at)`. Доска хранится целиком как JSON-массив элементов.

### API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/boards` | список досок |
| POST | `/api/boards` | создать доску `{name}` |
| GET | `/api/boards/:id` | доска + элементы |
| PUT | `/api/boards/:id` | сохранить `{elements}` (POST — алиас для sendBeacon) |
| DELETE | `/api/boards/:id` | удалить доску |
| POST | `/api/login` | вход по имени |

### WebSocket `/ws?board=<id>`

Клиент шлёт: `cursor {name, x, y, clientId}` (троттлинг 30 мс), `element:update {element}`, `element:delete {id}`. Сервер бродкастит всем остальным в комнате и рассылает `peers {count}`.

## Самотест

```bash
PORT=3013 node scripts/ws-smoke.mjs
```

Два WS-клиента в комнате `demo`: проверяются hello, счётчик участников, доставка `element:update` и `cursor` второму клиенту и отсутствие эха собственных сообщений.
